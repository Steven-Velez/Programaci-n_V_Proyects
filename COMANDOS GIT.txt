git init -------> iniciar git
git branch -M main -----------> cambiar master por main
git config --global user.name "tu nombre" ---------> configurar usuario
git config --global user.email "nombredeusuario@gmail.com" ---------> configurar correo
clear --------------> limpiar consola
git status --------------> mirar el estado de los archivos y commits
git add . -----------------> agregar todo al área de preparación
git commit -m "comentario"---------------> se guarda un commit
git push origin main ------- -----------> subir los commits a GitHub
git remote add origin <URL-de-tu-repositorio> ---------> conecta tu repositorio local con el repositorio remoto en GitHub

-------------------------------------------------------------------------
git log --graph --decorate --all --oneline -----------> lista de serial commits resumida
git config --global alias.nombredealias "log --graph --decorate --all --oneline" ------------> método de resumir comandosg
-------------------------------------------------------------------------

git checkout d06b776  ejemplo--> e069cb6 ---------> vuelve a una modificación anterior
touch .gitignore -------------> crea el archivo para ignorar librerías y carpetas pesadas (node_modules, etc.)

git tag -a v1.0 -m "mensaje" ------------> método de colocar versión a cada una de las actualizaciones del proyecto (Tag anotado)
git tag -------------> ver la lista de tags creados localmente
git push origin v1.0 --------------------> subir un tag específico a GitHub
git push origin --tags --------------------> subir todos los tags creados a GitHub de una sola vez

git tag -d nombre-del-tag --------------------> borrar un tag localmente
git push origin --delete nombre-del-tag --------------------> borrar un tag en GitHub (remoto)

git commit --amend -m "nuevo mensaje" -----------------> corregir el mensaje del último commit hecho
git reset --soft HEAD~1 -----------------> deshacer el último commit manteniendo los archivos intactos

v1.2.3
│ │ │

│ └─── MINOR: Nueva funcionalidad (cambios compatibles)
└───── MAJOR: CHANGES incompatibles con versiones anteriores

COMANDOS ADICIONALES RECOMENDADOS A FUTURO (Para tu semestre y proyectos):
------------------------------------------------------------------------------------------------------------------------
git pull origin main -------------> Descargar y fusionar los cambios de GitHub a tu computador (muy útil si trabajas desde varios PCs o en equipo)
git remote -v --------------------> Verificar cuál es la URL del repositorio remoto vinculado a tu proyecto
git diff -------------------------> Ver exactamente qué líneas de código cambiaste antes de hacer un add o commit
git branch -d nombre-rama --------> Borrar una rama local que ya no uses o que ya terminaste de fusionar
git stash -------------------------> Guardar temporalmente los cambios en los que estás trabajando sin hacer commit para limpiar la pantalla
